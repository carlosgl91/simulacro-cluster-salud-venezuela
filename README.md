# Simulacro público del Clúster Salud Venezuela

Tablero Streamlit de demostración adaptado a la estructura de F01 y F02 con datos históricos seleccionados. No contiene datos de contacto, direcciones detalladas, fotografías ni textos libres. Los nombres de organizaciones y lugares, así como las coordenadas históricas, sí son visibles públicamente. Las inversiones de ejemplo son ilustrativas y no representan registros de los nuevos F01 y F02.

Para desplegar en Streamlit Community Cloud, suba el contenido de esta carpeta a un repositorio de GitHub y use `app.py` como archivo principal.
